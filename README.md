### Sobre mí

Soy economista de la Universidad Nacional de San Cristóbal de Huamanga y trabajo donde se cruzan la economía, la
gestión pública y el software. Escribo código para que el trabajo diario de una oficina pública sea más simple:
documentos bien redactados y numerados, plazos que no se pierden, datos que se pueden consultar. También enseño e
investigo en economía, estadística y matemáticas.

📍 Ayacucho, Perú  
🔍 Economía · Gestión pública · Ciencia de datos · LaTeX y Quarto · Linux

### Lo que estoy construyendo

**[Qillqa](https://github.com/achalmed/qillqa)** es una plataforma de gestión documental para entidades públicas y
privadas: redacción con plantillas, numeración sin errores, PDF con LuaLaTeX, mesa de partes, plazos y seguimiento,
tareas, agenda y chat. Está hecha de módulos independientes que se conectan con **[Tiqsi](https://github.com/achalmed/tiqsi)**,
un contrato pequeño (manifiesto, capacidades, eventos y referencias) para que cada proyecto funcione solo o dentro
del anfitrión. Los nombres vienen del quechua.

| Módulo | Qué hace |
|---|---|
| [Qillqasqa](https://github.com/achalmed/qillqasqa) | Gestión documental, proyectos de ley e informes, con su marco LuaLaTeX y edición simultánea |
| [Punku](https://github.com/achalmed/punku) | Mesa de partes, con mesa virtual pública y cargo en PDF |
| [Minka](https://github.com/achalmed/minka) | Tareas y agenda del equipo |
| [Rimay](https://github.com/achalmed/rimay) | Chat del equipo, con tarjetas y avisos |
| [Rikchay](https://github.com/achalmed/rikchay) | Mediateca de fotos, videos y documentos |
| [Yupay](https://github.com/achalmed/yupay) | Rendición de cuentas de viáticos, con anexos en PDF y Excel |
| [Qhawana](https://github.com/achalmed/qhawana) | Observatorio de datos públicos |
| [Tullpu](https://github.com/achalmed/tullpu), [Kuyuy](https://github.com/achalmed/kuyuy), [Awana](https://github.com/achalmed/awana) | Editores de fotos, videos y piezas gráficas en el navegador, sobre [Ruray](https://github.com/achalmed/ruray) |
| [Wayra](https://github.com/achalmed/wayra) | Kit de transmisiones para OBS |

Python (FastAPI) · TypeScript (React) · PostgreSQL · LuaLaTeX. Las versiones públicas son de demostración (AGPL-3.0;
Tiqsi, Apache-2.0).
